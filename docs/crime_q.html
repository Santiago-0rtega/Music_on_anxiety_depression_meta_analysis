This chapter reproduces the CRIME-Q study-level rating figure from the cohort-level risk-of-bias assessment table and provides a compact item definition section for the CRIME-Q music-exposure codebook.

CRIME-Q study-level rating matrix

The source assessment contains 49 cohort rows from 20 studies. When a study has multiple cohorts, item ratings are collapsed to one display row: if all cohorts have the same rating, that rating is retained; if cohort ratings differ, the study is displayed as Partly.

plot_dat <- study_matrix |>
  pivot_longer(
    cols = all_of(item_cols),
    names_to = "Item",
    values_to = "Rating"
  ) |>
  mutate(
    Item = factor(Item, levels = item_cols),
    ID = factor(ID, levels = rev(unique(ID))),
    Fill_group = case_when(
      Rating == "Yes" ~ "Yes",
      Rating %in% c("Partly", "Unclear") ~ "Partly/Unclear",
      Rating == "No" ~ "No",
      Rating == "NA" ~ "NA",
      TRUE ~ "Other"
    )
  )

if (any(plot_dat$Fill_group == "Other")) {
  warning("Some unexpected CRIME-Q rating values were found.")
}

ggplot(plot_dat, aes(x = Item, y = ID, fill = Fill_group)) +
  geom_tile(color = "black", linewidth = 0.35) +
  scale_fill_manual(
    values = c(
      "Yes" = "#33FF33",
      "Partly/Unclear" = "#FFFF4D",
      "No" = "#FF3333",
      "NA" = "#1E3DFF"

    breaks = c("Yes", "Partly/Unclear", "No", "NA"),

    x = NULL,

1X: Peer review

Construct: Quality of reporting
Assessment level: Study-level
Rating options: Yes; No

What it checks: Did the paper undergo peer review before publication?

Simplified coding rule: Yes = full article in a scholarly journal. No = preprint, thesis, conference abstract, or other non-peer-reviewed report.

Note: Do not infer peer-review status from author affiliation.

2X: Bench-top/lab work: reporting

Construct: Quality of reporting
Assessment level: Study-level
Rating options: Yes; Partly; No; NA

What it checks: Are bench-top/laboratory procedures that establish the model sufficiently reported?

Simplified coding rule: Code only when such work materially establishes the model/intervention; otherwise NA with the reason recorded.

NA rule: NA (default) when no cell culture/surgery/genetic-model/compound-prep procedure is central to the study.

Note: Pre-specified deviation for acoustic music-exposure experiments.

2Y: Bench-top/lab work: technical quality

Construct: Methodological quality
Assessment level: Study-level
Rating options: Yes; Partly; No; NA

What it checks: Were those bench-top procedures technically adequate and appropriately implemented?

Simplified coding rule: Assess only if bench-top work materially establishes the model; otherwise NA.

NA rule: NA (default) as for 2X.

Note: Pre-specified deviation; document the NA.

3X: Animals: reporting

Construct: Quality of reporting
Assessment level: Study-level
Rating options: Yes; Partly; No

What it checks: Are experimental animals sufficiently described?

Simplified coding rule: Yes = species, strain/stock, sex, age/stage + body mass or supplier, and identifiable group sizes. Partly = some descriptors only. No = generic ‘rats/mice’ or seriously insufficient.

Note: Do not penalize early-life studies where sex is undeterminable; record stage.

3Y: Animals: technical quality

Construct: Methodological quality
Assessment level: Cohort-sensitive
Rating options: Yes; Partly; No

What it checks: Were animal characteristics comparable between groups and appropriate for the assay?

Simplified coding rule: Yes = groups comparable (strain/sex/age/baseline) and model appropriate. Partly = likely comparable but incompletely documented. No = relevant imbalance unaddressed or unsuitable model.

Note: A missing baseline table usually warrants Partly, not No.

3Z: Selection bias: baseline characteristics

Construct: Risk of bias
SYRCLE mapping: SYRCLE 2
Assessment level: Cohort-sensitive
Rating options: Yes; No; Unclear; NA

What it checks: Were relevant baseline characteristics balanced between music and control groups?

Simplified coding rule: Yes = arm-specific balance shown or matching/blocking/litter-balancing used. No = relevant imbalance shown and unaddressed. Unclear = no arm-specific baseline info or balancing procedure.

NA rule: NA only if a single group is genuinely relevant (rare).

4Y: Sample-size calculation

Construct: Methodological quality
Assessment level: Study-level
Rating options: Yes; Partly; No

What it checks: Did the study report an appropriate a priori sample-size calculation?

Simplified coding rule: Yes = a priori calculation with assessable assumptions appropriate to the music comparison. Partly = mentioned but incomplete or post hoc. No = none reported.

Note: ‘Sample size followed prior studies’ is not a calculation.

5X: In vivo design & performance: reporting

Construct: Quality of reporting
Assessment level: Cohort-sensitive
Rating options: Yes; Partly; No

What it checks: Is the music-exposure experiment described sufficiently for replication?

Simplified coding rule: Yes = all core elements reported (stimulus; delivery hardware/arrangement; sound level; schedule/timing; control condition; housing; assay; induction). Partly = one or more core elements missing. No = no reproducible music-vs-control experiment identifiable.

Note: List each core element as reported or NR even when overall = Yes.

5Y: In vivo design & performance: technical quality

Construct: Methodological quality
Assessment level: Cohort-sensitive
Rating options: Yes; Partly; No

What it checks: Does the described music-exposure design appear technically feasible for the stated aim?

Simplified coding rule: Yes = plausibly delivers distinct music/control; no obvious acoustic cross-contamination, pseudoreplication, or fatal timing flaw. Partly = plausible but key info incomplete. No = clear technical problem threatening interpretability.

Note: Do not judge whether a genre ‘should work’.

5Z(1): Selection bias: sequence generation

Construct: Risk of bias
SYRCLE mapping: SYRCLE 1
Assessment level: Study-level
Rating options: Yes; No; Unclear; NA

What it checks: Was allocation to groups generated by an appropriate random method?

Simplified coding rule: Yes = described, plausibly random method (RNG, random-number table, drawing lots). No = clearly non-random (alternation, arrival order, convenience). Unclear = ‘randomly assigned’ with no method or no details.

NA rule: NA only for non-interventional designs (rare here).

5Z(2): Performance bias: random housing

Construct: Risk of bias
SYRCLE mapping: SYRCLE 4
Assessment level: Cohort-sensitive
Rating options: Yes; No; Unclear; NA

What it checks: Were animals randomly housed or protected from systematic cage/position effects?

Simplified coding rule: Yes = random placement/counterbalancing/rotation addressing position and acoustic environment. No = systematic placement confounded with condition, unmitigated. Unclear = housing not reported sufficiently.

NA rule: NA only if housing position cannot affect the experiment (unlikely for acoustic studies).

5Z(3): Detection bias: random outcome assessment

Construct: Risk of bias
SYRCLE mapping: SYRCLE 6
Assessment level: Cohort-sensitive
Rating options: Yes; No; Unclear; NA

What it checks: Were animals assessed according to a pre-specified, unbiased selection rule?

Simplified coding rule: Yes = all allocated animals tested at a pre-specified time, or a random/pre-specified selection rule. No = selection based on post-allocation response/survival. Unclear = cannot tell who was assessed or how.

NA rule: NA only if no animal-level outcome assessment is relevant.

6X: Animal-welfare compliance

Construct: Quality of reporting
Assessment level: Study-level
Rating options: Yes; Partly; No

What it checks: Did the study report compliance with animal-welfare regulations?

Simplified coding rule: Yes = ethics/animal-care approval or guideline compliance explicitly reported. Partly = general welfare statement, details incomplete. No = none reported.

7X: Blinding: reporting

Construct: Quality of reporting
Assessment level: Study-level
Rating options: Yes; Partly; No

What it checks: Does the report describe blinding in any relevant phase?

Simplified coding rule: Yes = states who was blinded, at what stage, and to which condition(s). Partly = unqualified ‘blinded’ or limited detail. No = no blinding described.

Note: Automated tracking is not, by itself, evidence of blinding.

7Z(1): Performance bias: caregiver/researcher blinding

Construct: Risk of bias
SYRCLE mapping: SYRCLE 5
Assessment level: Cohort-sensitive
Rating options: Yes; No; Unclear; NA

What it checks: Were caregivers/researchers conducting the intervention blinded where feasible?

Simplified coding rule: Yes = procedures prevented handling staff from knowing assignment, or coded conditions. No = explicitly unblinded with plausible influence on handling/treatment. Unclear = no adequate information.

NA rule: NA only where blinding is genuinely impossible and no handling influence is plausible (explain); not merely because the intervention is music.

7Z(2): Allocation bias: allocation concealment

Construct: Risk of bias
SYRCLE mapping: SYRCLE 3
Assessment level: Study-level
Rating options: Yes; No; Unclear; NA

What it checks: Could the person assigning animals foresee the next assignment?

Simplified coding rule: Yes = concealed (central coded allocation, sealed opaque envelopes, independent allocator). No = predictable or allocator could influence placement. Unclear = not described.

NA rule: NA only for non-interventional designs.

Note: Randomization alone does not establish concealment.

7Z(3): Detection bias: outcome-assessor blinding

Construct: Risk of bias
SYRCLE mapping: SYRCLE 7
Assessment level: Cohort-sensitive
Rating options: Yes; No; Unclear; NA

What it checks: Were outcome assessors blinded to music/control assignment?

Simplified coding rule: Yes = assessors/coders/analysts blinded, or data masked before outcome extraction. No = explicitly unblinded with a judgment-sensitive outcome. Unclear = not reported.

NA rule: NA only for an outcome with no assessor-dependent stage (explain).

Note: Automated tracking alone does not justify Yes unless masking is described.

8X: Methods-results congruency

Construct: Quality of reporting
Assessment level: Cohort-sensitive
Rating options: Yes; Partly; No

What it checks: Are reported methods and results coherent and transparent?

Simplified coding rule: Yes = outcomes/labels/n/timing/analyses correspond to methods; results traceable. Partly = minor discrepancies, primary comparison still interpretable. No = major mismatches or untraceable results.

8Z(1): Attrition bias: incomplete outcome data

Construct: Risk of bias
SYRCLE mapping: SYRCLE 8
Assessment level: Cohort-sensitive
Rating options: Yes; No; Unclear

What it checks: Were outcome data complete, with exclusions/attrition adequately handled?

Simplified coding rule: Yes = numbers allocated/analysed/excluded clear by group with reasons (or all contributed). No = missing/excluded unequal, outcome-related, or inadequately explained. Unclear = denominators/exclusions insufficiently reported.

Note: Not ‘No’ merely because an animal died or was excluded.

8Z(2): Reporting bias: selective outcome reporting

Construct: Risk of bias
SYRCLE mapping: SYRCLE 9
Assessment level: Cohort-sensitive
Rating options: Yes; No; Unclear

What it checks: Were prespecified or expected outcomes fully reported?

Simplified coding rule: Yes = protocol matches, or methods list outcomes and results give all corresponding group-level results. No = a key outcome missing, selective reporting, or outcome switching. Unclear = no protocol and cannot compare intended vs reported.

Note: Absence of a protocol alone is not enough for No.

9X: Presentation of limitations

Construct: Quality of reporting
Assessment level: Study-level
Rating options: Yes; Partly; No

What it checks: Did the authors acknowledge relevant study limitations?

Simplified coding rule: Yes = substantive limitations linked to the experiment/model/measures/design. Partly = generic or brief statement. No = none discussed.

10X: Conflict-of-interest statement

Construct: Quality of reporting
Assessment level: Study-level
Rating options: Yes; No

What it checks: Did the paper include a conflict-of-interest/competing-interests declaration?

Simplified coding rule: Yes = formal statement present (including a declaration of no conflicts). No = no such statement in paper or supplement.

10Z: Other bias: funder/commercial influence

Construct: Risk of bias
SYRCLE mapping: SYRCLE 10 (adapted)
Assessment level: Study-level
Rating options: Yes; No; Unclear

What it checks: Was the study apparently free from inappropriate funder or commercial influence?

Simplified coding rule: Yes = no relevant conflict declared and no inappropriate sponsor role evident. No = a funder/company with a relevant interest controlled or materially influenced design/conduct/analysis/reporting, or an undeclared conflict. Unclear = conflict/sponsor-role info absent.

Note: Academic/public funding is not a bias signal by itself.

```{r}
#| label: crimeq-load
#| include: false

input_file <- here("..", "data", "MUSIC-CRIME-Q_RoB_assessment.xlsx")
input_sheet <- "Table 2"
codebook_file <- here("..", "CRIME-Q_Music_RoB_Codebook_v1.8.csv")

item_cols <- c(
  "1X", "2X", "2Y", "3X", "3Y", "3Z", "4Y",
  "5X", "5Y", "5Z(1)", "5Z(2)", "5Z(3)",
  "6X", "7X", "7Z(1)", "7Z(2)", "7Z(3)",
  "8X", "8Z(1)", "8Z(2)", "9X", "10X", "10Z"
)

expected_cols <- c("Study_ID", "Cohort_ID", item_cols)

cohort_matrix <- read_excel(
  path = input_file,
  sheet = input_sheet,
  col_types = "text",
  na = ""
) |>
  rename_with(str_trim) |>
  mutate(across(everything(), str_trim)) |>
  select(all_of(expected_cols))

if (!identical(names(cohort_matrix), expected_cols)) {
  stop("Sheet 'Table 2' does not match the expected column structure.")
}

if (anyDuplicated(cohort_matrix$Cohort_ID) > 0) {
  stop("Duplicated Cohort_ID values detected.")
}

collapse_rating <- function(x) {
  vals <- unique(x)
  if (length(vals) == 1L) vals else "Partly"
}

study_matrix <- cohort_matrix |>
  group_by(Study_ID) |>
  summarise(
    across(all_of(item_cols), collapse_rating),
    .groups = "drop"
  ) |>
  arrange(Study_ID) |>
  mutate(ID = row_number()) |>
  relocate(ID, .before = Study_ID)

codebook <- read_csv(
  codebook_file,
  show_col_types = FALSE,
  trim_ws = TRUE
) |>
  arrange(Order)

if (!identical(codebook$Item, item_cols)) {
  stop("Codebook item order does not match the CRIME-Q matrix columns.")
}
```

```{r}
construct_labels <- c(
  QoR = "Quality of reporting",
  MQ = "Methodological quality",
  RoB = "Risk of bias"

codebook |>
  transmute(
    Item,
    Construct = recode(Construct, !!!construct_labels),

    `Ratings` = Response_options
```

```{r}
#| label: crimeq-item-definitions
#| echo: false
#| results: asis

clean_field <- function(x) {
  x <- str_squish(as.character(x))
  ifelse(is.na(x) | x == "" | x == "-", NA_character_, x)
}

for (i in seq_len(nrow(codebook))) {
  row <- codebook[i, ]
  construct <- recode(row$Construct, !!!construct_labels)
  syrcle <- clean_field(row$SYRCLE_item)
  na_rule <- clean_field(row$NA_rule)
  notes <- clean_field(row$Notes)

  cat("### ", row$Item, ": ", row$Domain, "\n\n", sep = "")
  cat("**Construct:** ", construct, "  \n", sep = "")
  if (!is.na(syrcle)) {
    cat("**SYRCLE mapping:** ", syrcle, "  \n", sep = "")
  }
  cat("**Assessment level:** ", row$Assessment_level, "  \n", sep = "")
  cat("**Rating options:** ", row$Response_options, "\n\n", sep = "")
  cat("**What it checks:** ", row$Question, "\n\n", sep = "")
  cat("**Simplified coding rule:** ", row$Operational_guidance, "\n\n", sep = "")
  if (!is.na(na_rule) && na_rule != "Not used") {
    cat("**NA rule:** ", na_rule, "\n\n", sep = "")
  }
  if (!is.na(notes)) {
    cat("**Note:** ", notes, "\n\n", sep = "")
  }
}
```
