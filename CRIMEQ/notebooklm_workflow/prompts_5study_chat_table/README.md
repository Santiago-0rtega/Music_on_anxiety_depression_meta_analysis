# Five-Study Chat Markdown Table Prompts

These prompts ask NotebookLM for a normal Markdown table instead of TSV. Use
these when TSV output collapses into one physical line.

Use one clean NotebookLM notebook per five-study batch. Upload only the five
target PDFs plus the current manifest, codebook, general instructions,
calibration rules, and column template.

Run one prompt manually in NotebookLM, copy the resulting table, and review it
with `../MANUAL_REVIEW_CHECKLIST.md` before continuing.
