# CRIMEQ

This folder contains the CRIME-Q and NotebookLM extraction materials for the
music anxiety/depression meta-analysis.

## Folders

- `notebooklm_workflow/`: finalized public-facing NotebookLM workflow,
  prompts, manifests, shared rules, and manual review checklist.
- `notebooklm_workflow/batches/*/pdfs/`: local ignored PDFs organized by batch
  for private testing. These PDFs are not part of the public supplement.
- `archive/`: previous prompt/instruction drafts and older NotebookLM workflow
  experiments, including `previous_notebooklm_materials_2026-06-29.zip` and
  `working_uploads_2026-06-29.zip`.

Use `notebooklm_workflow/README.md` as the entry point for the reproducible
NotebookLM extraction workflow.
